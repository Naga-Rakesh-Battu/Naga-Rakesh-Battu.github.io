# Naga Rakesh Battu: portfolio

Personal portfolio site: AI/ML engineer building reliable, cost-aware LLM applications.

A single static page (`index.html`, no build step, no dependencies).

## Put it online with GitHub Pages

1. Create a repository named `Naga-Rakesh-Battu.github.io` (or any name).
2. Upload `index.html`, `README.md` and `Naga_Rakesh_Battu_Resume.pdf` to the repository root.
3. Open **Settings → Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After a minute the site is live at `https://naga-rakesh-battu.github.io/`.
